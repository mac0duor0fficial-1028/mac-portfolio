Macphalen L. Oduor - Data Engineer Portfolio
============================================

RUN LOCALLY
1. Unzip this folder.
2. Double-click index.html (opens in your browser).
   Or serve it:  python -m http.server 8000   then visit http://localhost:8000

NOTE: Needs an internet connection on first load (Tailwind CSS, Lucide icons
and Google Fonts load from CDNs).

EDIT YOUR CONTENT
Open index.html in a text editor and search for "// --- DATA ---". Everything
is there: TECH_STACK, PIPELINE_LINEAGE, PROJECTS, EXPERIENCE (add your jobs
here) and BLOG_POSTS (swap in real articles).
Contact details are in the Contact section and in downloadResume().

DEPLOY FREE
Push index.html to a GitHub repo and enable Pages (Settings > Pages), or drag
the folder into Netlify / Cloudflare Pages.
